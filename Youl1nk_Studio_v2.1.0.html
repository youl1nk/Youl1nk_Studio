Project Inspector — understand your project

Open an HTML project to map its header, title, content, images, audio, buttons, and other detected areas. Choose a target before adding content.

AUTO-DETECT

1. Project analysis

No project analyzed yet. Open an HTML file to see its structure.

Example structureHeader → Main/Body → Section → Footer

2. Choose a content location

New content will be inserted into your chosen area instead of being placed at the bottom by default.

Rule: use <main> when available; otherwise use <body>.

3. Image settings

The image will be embedded in the standalone HTML file. Choose its location and display size.

4. Audio / music settings

Choose the player location and playback behavior. Browsers usually block autoplay with sound until the user interacts with the page.

Note: detection reads common HTML structures. Projects that build pages dynamically with JavaScript, use frameworks, or have unusual structures may need manual review. Images and audio are embedded as data URLs; large media files increase the HTML file size.
VISUAL EDITING WITHOUT CODING

Visual Mode — edit page content and appearance

Choose an element, change its text or style, and select Apply. Changes are written directly to your HTML project.

VISUAL MAKER

A. Page identity

The project name used for the exported file is different from the browser tab title. You can change both.

B. Edit an existing element

Choose an element detected during analysis, such as a heading, paragraph, button, section, or footer.

C. Style an element

Set the text color, background, font size, and alignment for the selected element.

D. Add a ready-made element

Create a section, card, or banner without writing HTML. The location follows your Project Explorer selection.

Important: visual changes are applied to the HTML currently in the editor. The original file on your computer is not overwritten; download the edited file yourself. Projects using frameworks or JavaScript-generated interfaces may require code editing.

Beginner Mode — build a page without writing code

Choose what to add, fill in the fields, and press the button. The HTML will be generated automatically.

NO CODING REQUIRED

1. Header / introduction

The top of the page, with a main heading and short introduction.

2. Body / text content

For paragraphs, stories, information, or the main explanation.

3. Image / photo

Choose an image from your computer. It will be embedded in the HTML so it stays in one file.

4. Audio / music

Choose an audio file from your computer. It will be embedded in the HTML, which may increase file size.

5. Button / link

Create a button that links to another page or URL.

6. How it works

New content will be inserted into <body> HTML.

After adding a section, select Run Preview to preview the result. When you are satisfied, select Download HTML.

Tip: you can still edit the code manually in the left panel. Beginner Mode simply generates starter markup.
