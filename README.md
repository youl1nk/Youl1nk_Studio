# Youl1nk Studio

**A simple, beginner-friendly HTML editor and website maker.**

Youl1nk Studio is a lightweight, browser-based tool designed to make editing and creating HTML projects easier for everyone, including people with little or no coding experience.

Instead of relying entirely on a code editor, users can explore their HTML structure, edit content, customize visual styles, add new sections, preview changes in real time, and export their work as an HTML file.

## Features

- **HTML Editor** — Open and edit existing HTML files directly in your browser.
- **Live Preview** — Preview your website while making changes.
- **Visual Editing** — Customize supported elements, text, colors, font sizes, and alignment without manually writing every line of code.
- **Project Explorer** — Inspect common HTML elements such as headers, sections, images, audio, buttons, and links.
- **Section Maker** — Create and insert new content sections into your project.
- **Media Support** — Add images and audio to supported HTML layouts.
- **Project Naming** — Set a project name for your exported HTML file.
- **HTML Export** — Download your edited project as an HTML file.
- **Beginner-Friendly Interface** — Designed to make HTML projects easier to understand and manage.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open `Youl1nk_Studio_v2.0.0.html` in a modern web browser.
3. Open an existing HTML file or start creating a new project.
4. Edit your project using the code editor, visual tools, or section maker.
5. Preview your changes and export the resulting HTML file.

No traditional installation is required for the standalone HTML version.

Project Goal

Youl1nk Studio aims to bridge the gap between traditional HTML coding and visual website creation.

The goal is to help beginners understand what makes up a website while giving them practical tools to create, customize, and edit their own projects.

⚠️ Limitations

Youl1nk Studio is primarily designed for standalone HTML projects. Websites that depend on external CSS files, JavaScript modules, frameworks, server-side code, or complex project structures may require additional manual configuration.

Not every HTML element or script can be safely or accurately edited through visual tools. Always keep a backup of important projects before making changes.
